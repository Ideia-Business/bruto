# Organização por assunto usa Tag plana, não Categoria hierárquica

O pedido original era uma hierarquia — subcategorias de IA crescendo dentro de "Tecnologia" à
medida que o catálogo aprofunda o assunto. Rejeitado por risco de explosão: sem uma lista de
subcategorias existentes para a IA reaproveitar, a primeira reclassificação de um catálogo
inteiro criaria dezenas de rótulos quase-iguais ("Agentes de IA", "IA Agêntica", "Fluxos com
IA") para o mesmo conceito — pior que a classificação rasa que motivou a mudança.

Decisão: a Categoria de topo (nove valores fixos) permanece intacta e estável para navegação;
por baixo dela, a IA atribui **Tags** — planas, várias por vídeo, reaproveitadas de uma lista
existente antes de criar uma nova, sem tela própria (aparecem como filtro dentro do Catálogo).
Trade-off: perde a leitura hierárquica explícita ("Tecnologia > Agentes de IA"), ganha um
mecanismo de anti-duplicação mais simples de implementar e de a IA acertar de primeira.
